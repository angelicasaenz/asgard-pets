**Asgard Pets** es un proyecto de aprendizaje colaborativo en Java enfocado en el desarrollo backend. El sistema simula la gestión comercial de una empresa dedicada a la distribución de alimentos, medicamentos y accesorios para mascotas.

El objetivo principal de este repositorio es reflejar una ruta de aprendizaje incremental y profesional, evolucionando desde los fundamentos en consola hasta un ecosistema **API REST con Spring Boot y MySQL**, con miras a una aplicación web **Fullstack**.

## 🔀 Navegación por Ramas (Branches)

Puedes explorar el código en sus diferentes etapas de evolución cambiando de rama en el repositorio:

- 📦 **`feature/estructura-poo`**: Implementación del núcleo en POO pura, colecciones en memoria y arquitectura en capas por consola.
- 🚀 **`feature/spring-boot`**: Migración activa hacia la arquitectura API REST con Spring Boot, Spring Data JPA y MySQL.

---

## 📖 Estado del Proyecto y Evolución

### ✅ v1.0 - Fundamentos y Programación Estructurada
- Lógica inicial con programación estructurada, arreglos y condicionales.
- Lectura y validación de datos por consola (`Scanner`).

### ✅ v2.0 - Core POO y Colecciones en Memoria
- Reestructuración completa aplicando **Programación Orientada a Objetos** y Colecciones (`ArrayList`).
- **Gestión de Inventario (Distribuidora):** CRUD completo de productos.
- **Gestión de Ventas y Usuarios:** Clientes, empleados, administradores y proveedores mediante herencia, polimorfismo y generación de facturas.
- **Arquitectura en Capas:** Separación por paquetes (`model`, `service`, `util`, `view`).

### 🔄 v3.0 - API REST Backend con Spring Boot y MySQL (En Progreso)
- Migración hacia una arquitectura web desacoplada **API REST**.
- Mapeo de entidades y persistencia relacional con **Spring Data JPA** / **Hibernate**.
- Base de datos relacional integrada con **MySQL Workbench**.
- Controladores REST (`@RestController`) para exponer *endpoints* de gestión comercial.

### 📅 v4.0 - Aplicación Web Fullstack
- Integración con interfaz web (*Frontend*).
- Autenticación y control de acceso seguro.

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (JDK 17+)
- **Framework Backend:** Spring Boot 3
- **Persistencia & BD:** Spring Data JPA, Hibernate, MySQL / MySQL Workbench
- **Entorno de Desarrollo:** IntelliJ IDEA
- **Control de Versiones:** Git y GitHub (Feature Branching & Pull Requests)
- **Modelado & Documentación:** Markdown, StarUML, Postman

---

## 📚 Conceptos Aplicados

- **Paradigma POO:** Encapsulamiento, Herencia, Polimorfismo, Clases Abstractas e Interfaces.
- **Patrones y Arquitectura:** Arquitectura en capas (*Layered Architecture*), DTOs y principios SOLID.
- **Estructuras de Datos:** Manejo de Colecciones dinámicas (`List`, `ArrayList`, `Map`).
- **Desarrollo Web Backend:** Diseño de APIs RESTful, manejo de peticiones HTTP, anotaciones de Spring Boot.
